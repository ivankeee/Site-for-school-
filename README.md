# Искусственный интеллект в повседневной жизни

Индивидуальный итоговый проект. Автор: Васильев Иван Алексеевич, 10 «К» класс, МАОУ «ДОК „Орбита“».

## Что это
Одностраничный интерактивный образовательный сайт: 9 разделов + 3 эксперимента (викторина «Человек или ИИ?», обучение нейросети в браузере, счётчик ИИ-взаимодействий). Всё в одном файле `index.html` — без серверов и библиотек.

## Как опубликовать на GitHub Pages (с ПК)
1. Создайте новый репозиторий: github.com/new → имя любое (например `ai-project`), Public → **Create repository**.
2. В репозитории: **Add file → Upload files** → перетащите `index.html` и `.nojekyll` → **Commit changes**.
3. **Settings → Pages** → Branch: `main`, папка `/(root)` → **Save**.
4. Через 1–2 минуты сайт будет по адресу: `https://ВАШ_НИК.github.io/ИМЯ_РЕПО/`

## Локальный просмотр
Просто откройте `index.html` двойным щелчком — работает без интернета.
